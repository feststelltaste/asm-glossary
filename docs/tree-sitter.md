# Tree-sitter

![tree-sitter](assets/images/en/tree-sitter.png)

> A fast, incremental parser library that builds a concrete syntax tree for source code in any supported language. Agents and tools use Tree-sitter to navigate and query code structure without a full language server, making it a lightweight alternative for tasks like finding function boundaries, extracting symbol names, or identifying structural patterns across large codebases.
