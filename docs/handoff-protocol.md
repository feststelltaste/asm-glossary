# Handoff Protocol

![handoff-protocol](assets/images/en/handoff-protocol.png)

> The structured, self-contained package of context that accompanies work passed from one agent to another or from an agent to a human. Because the receiver has no access to the sender's session, the handoff must carry everything needed to act: identifiers, a summary of what happened, the root cause analysis, and a recommended action. A handoff that states what to do without why, or that assumes the receiver can read the original conversation, leaves receivers unable to verify or complete the work.
