# Adversarial Review

![adversarial-review](assets/images/en/adversarial-review.png)

> The practical technique that operationalizes the fix for self-review bias: a fresh agent instance reviews only the artifact under review, with no access to the session or reasoning that produced it, and is explicitly instructed to find fault rather than approve. Where Self-Review Bias names why same-session review fails, Adversarial Review is the concrete pattern teams implement to avoid it. For higher-stakes changes, the pattern can be escalated to multiple independent adversarial passes, or paired with LLM as a Judge to formalize the verdict.
