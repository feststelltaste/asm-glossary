# Context Drift

![context-drift](assets/images/en/context-drift.png)

> The gradual loss, distortion, or forgetting of original instructions and intent as a conversation or task with an agent grows longer. As turns accumulate and context shifts, the agent may silently reinterpret goals, adopt inconsistent conventions, or lose track of earlier constraints. Context drift is a key driver of context rot and can be mitigated through periodic re-anchoring to the original task specification.
