# Narrator Agent

![narrator-agent](assets/images/en/narrator-agent.png)

> An agent that continuously documents what other agents did and why, so the humans responsible for the system retain understanding of changes they did not write. By turning raw agent activity into readable worklogs, migration summaries, or learnings overviews, it counters the comprehension debt and dark code that high volume agent output otherwise creates. Its explanations become part of the project record, useful for onboarding, audits, and retrospectives.
