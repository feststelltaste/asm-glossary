# Language Server Protocol (LSP)

![language-server-protocol](assets/images/en/language-server-protocol.png)

> A standardized protocol that enables tools and agents to query a language server for semantic information about a codebase: symbol definitions, all references to a name, call hierarchies, and type information. Agents equipped with LSP access navigate code with the precision of an IDE rather than relying on text search, which reduces false positives and missed usages when analyzing or transforming large codebases.
