# Leitplanken

![leitplanken](assets/images/leitplanken.png)

> Einschränkungen und Sicherheitsmechanismen, die verhindern, dass ein Agent unkontrolliert destruktive Änderungen vornimmt. Dazu gehören Scope-Begrenzungen, Test-Gates, Rollback-Regeln und Approval-Workflows. Leitplanken sind kein Misstrauensvotum gegen den Agent, sondern gutes Engineering: Wie ihr Namensvorbild auf der Autobahn geben sie Sicherheit, ohne die Fahrt zu blockieren.
