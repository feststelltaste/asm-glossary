# Portierungsleitfaden

![portierungsleitfaden](assets/images/portierungsleitfaden.png)

> Ein lebendes Referenzdokument, das festlegt, wie Konstrukte, Idiome und Muster der Ausgangssprache auf die Zielsprache abgebildet werden, damit jeder an einer Portierung beteiligte Agent auf dieselbe Weise übersetzt. Serialisierte Teamdiskussion wird zum schriftlichen Vertrag: Statt dass jeder Agent seine eigene Abbildung erfindet, konsultieren alle eine Autorität, was eine massiv parallele Portierung konsistent hält und Reviews gegen eine Regel prüfbar macht. Popularisiert durch große agentengetriebene Neuimplementierungen wie die Bun-Portierung nach Rust mit ihrer PORTING.md.
