# Variantenanalyse

![variantenanalyse](assets/images/variantenanalyse.png)

> Eine Technik, bei der ein Mensch zunächst eine einzelne Instanz eines Musters wie einen Fehler, eine Schwachstelle oder einen Code Smell entdeckt und bestätigt. Ein Agent verallgemeinert dieses Beispiel anschließend zu einer Abfrage oder Regel und wendet sie auf die gesamte Codebasis oder eine Flotte von Repositories an. Der Agent findet dabei jede passende Variante, auch wenn sich der Code syntaktisch unterscheidet, oft gestützt auf einen Code-Wissensgraphen oder eine Analyse-Engine. So wird ein manuell gefundenes Problem zu einem vollständigen, vom Agenten erstellten Inventar aller Stellen, an denen dasselbe Problem auftritt, während die erste Beurteilung beim Menschen bleibt.
