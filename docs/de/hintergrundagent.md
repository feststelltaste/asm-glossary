# Hintergrundagent

![hintergrundagent](assets/images/hintergrundagent.png)

> Ein Agent, der weder durch einen Migrationsschritt noch durch einen Nutzer ausgelöst wird, sondern durch Zeit oder einen Systemzustand: eine nächtliche Abhängigkeitsprüfung, eine verletzte Fitnessfunktion, ein wachsender Fehlerbestand. Während Unteragenten auf Abruf innerhalb eines orchestrierten Ablaufs arbeiten, laufen Hintergrundagenten daneben her, beobachten fortlaufend die Bedingungen, für die sie zuständig sind, und handeln, sobald diese eintreten. Sie erweitern die agentische Modernisierung von aktiv gesteuerten Schritten hin zur laufenden Pflege des Vorhabens selbst.
