# Multi-Pass-Review

![multi-pass-review](assets/images/multi-pass-review.png)

> Eine Review-Architektur, die einen einzigen Durchlauf über eine große Änderung durch mehrere fokussierte Durchgänge ersetzt: Jede Datei und jedes Element erhält einen eigenen Durchgang mit voller Aufmerksamkeit, gefolgt von einem separaten Integrationsdurchgang für Belange, die sich über Elemente erstrecken, etwa inkonsistente Schnittstellen oder Datenflüsse. Das wirkt der Aufmerksamkeitsverwässerung direkt entgegen, die auch ein größeres Kontextfenster nicht behebt, und erzeugt gleichmäßige Review-Tiefe über die gesamte Änderung. Widersprüchliche Urteile über identischen Code in verschiedenen Dateien sind das verräterische Zeichen, dass ein Review in einem einzigen Durchgang an seine Grenzen gestoßen ist.
