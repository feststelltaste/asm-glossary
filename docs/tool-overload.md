# Tool Overload

![tool-overload](assets/images/en/tool-overload.png)

> The degradation in an agent's tool selection that sets in when too many tools compete for its attention, typically beyond four or five per agent. Symptoms include slow decisions, wrong tool picks, and agents drifting outside their intended role, for example a search agent that starts summarizing on its own. The remedy is scoped tool access: split responsibilities into role-specific agents that each carry only the few tools their specialty requires, and treat a growing tool list as an architectural smell rather than a description problem.
